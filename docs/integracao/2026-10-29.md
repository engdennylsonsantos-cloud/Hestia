## Como começar uma frente nova

1. Sempre saia do `main` atualizado:
   ```powershell
   git switch main
   git pull
   git switch -c feat/minha-frente
   ```
2. Prefira um worktree por frente:
   ```powershell
   git worktree add ..\wt\minha-frente -b feat/minha-frente main
   ```
3. Não trabalhe direto no `main` e não commite em branch de outra pessoa.
4. Antes de abrir PR: `typecheck`, `lint`, `test:rapido` e, se tocar IFC, `test:ifc-export` + `ifc:quality`.
