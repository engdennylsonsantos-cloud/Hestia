3. Principais Padrões Ergonômicos do Revit

  • Ribbon com Ícones Grandes e Pequenos: No Revit, as ações principais (Wall, Door, Window, Stair, Roof) usam ícones de 32x32 com texto abaixo; ferramentas secundárias se agrupam em colunas verticais com ícones de 16x16. O Hestia usa todos os botões no mesmo tamanho médio (48px com ícone de 22px).
  • Aba Contextual Verde (Modify | [Element]): Ao selecionar um elemento ou disparar uma ferramenta de croqui, o Revit abre uma aba de destaque verde vibrante com as opções de finalização (✔ Concluir / ✖ Cancelar modo croqui) e modificadores directos (Move, Copy, Rotate, Mirror).
  • Barra de Opções (Options Bar): Fica imediatamente abaixo do Ribbon e exibe parâmetros de criação imediata (ex: altura desconectada, linha de localização da parede, chain/cadeia, offset de cota). O Hestia já possui uma `OptionsBar`, o que é uma excelente conformidade com o Revit.
  • View Control Bar (Barra de Controle de Vista): No Revit, a escala (1:50, 1:100), o nível de detalhe (Baixo, Médio, Alto), o estilo visual (Linha Oculta, Sombreado, Cores Consistentes, Textura) e o controle de sombras ficam encostados na borda inferior do canvas, nunca em menus escondidos.
  • Disposição dos Painéis: No Revit clássico, tanto as Propriedades quanto o Project Browser ficam empilhados na esquerda (ou o navegador como aba acoplada). No Hestia atual, Propriedades fica na esquerda e o Navegador fica na direita.
